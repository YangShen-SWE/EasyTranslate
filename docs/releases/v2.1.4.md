## 分类规则与用户影响

| 输入或边界 | 分类 | 恢复方向 |
|---|---|---|
| 无密钥/空白密钥 | MISSING_KEY | 在设置中保存密钥；不发HTTP |
| 密钥读取异常或非法请求头值 | KEY_UNREADABLE | 在设置中重新保存；不发HTTP |
| HTTP 401/403 | AUTHENTICATION | 检查密钥有效性与权限 |
| HTTP 429 | RATE_LIMIT | 稍后手动重试 |
| HttpTimeoutException | TIMEOUT | 稍后手动重试，不混为普通网络错误 |
| 其他IOException | NETWORK | 检查网络后重试 |
| 空body/空choices/null或空白content | EMPTY_RESPONSE | 稍后手动重试 |
| JSON语法/结构/类型异常、尾随内容 | INVALID_RESPONSE | 重试；持续失败检查服务状态 |
| HTTP 500–599 | SERVICE_UNAVAILABLE | 稍后手动重试 |
| 其他非200状态（包括402） | REQUEST_REJECTED | 检查账户额度与服务设置，不伪断言具体原因 |
| 请求中断 | INTERRUPTED | 恢复线程中断标记；重新触发 |
| 未识别异常/过深异步包装 | UNKNOWN | 安全通用建议，不转述外部诊断 |

服务不自动等待Retry-After或自动重复请求。应用层send次数不等同底层网络报文次数，也不保证服务商不会计费；失败/丢弃旧回调并不取消在途HTTP。
