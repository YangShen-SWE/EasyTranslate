# v2.1.11 — D11构建和版本门禁

实际执行2026-10-22 00:33–00:38后（Europe/Copenhagen）；原计划2026-10-21。源码版本以模块pom.xml的project.version为准：2.1.10→2.1.11。这不是新的Windows安装包或GitHub Release。

## 改动与价值

- 显式固定原本默认实际使用的maven-jar-plugin 2.4，不升级依赖，并把Implementation-Version从project.version写入Manifest。
- 新增离线BuildArtifactVerifier及JUnit：读取当前pom确定产物名，检查内嵌Maven坐标、Manifest、真实模块版本及应用/FXML/CSS必需条目，输出SHA-256。无参数只读；不读取个人配置，不启动主程序/钩子/HTTP。
- 修复“文件名新、模块版本旧”的构建流程盲点：仅改pom时增量编译可能保留旧module-info.class。显式--stamp-module-version先验证文件名/坐标/Manifest/必需条目，再用JDK jar工具写归档模块版本并完整复查；拒绝把旧包重命名/改坐标冒充新包，不删除target/classes或历史产物。下次package后仍必须重复准备/校验。
- 固化构建和打包边界指南，核对完整JDK内置JavaFX与Maven声明的真实差异。未改变业务源码/FXML/CSS、module-info、运行依赖和README现有2.1.0下载。
