# v2.1.3 — D03 operation states / 本次操作状态与上次结果标记

日期：2026-10-13（Europe/Copenhagen）。内部源码更新，不是安装包发布。

## 当天目标与实际改动

- 模块pom.xml的project.version由2.1.2递增到2.1.3。未升级依赖、变动module-info或替换README已发布2.1.0安装包链接；当前应用标题没有版本消费者，本次未打包。
- 新增TranslationOperation：等待、读取、翻译、成功、未选中、无法读取、失败。TranslateSelectionUseCase增加进度回调重载，保留旧构造器及execute入口；None/Unknown不再在展示层混为沉默的空结果，均不调用翻译服务。
- LatestTranslationCoordinator将读取/进度/终态全部交给同一串行FIFO UI执行器（生产Platform.runLater），UI任务内复查触发意图编号及关闭状态；旧成功、旧失败和旧进度都不能更新最新状态。工作执行器拒绝时发布失败，不让最新操作永远停在读取。
- FloatingViewModel单独持有本次操作与状态文案，保留既有原文/译文。当最新操作不是成功且有保留译文时，状态栏后缀为“· 上次结果”。没有译文时不虚称存在上次结果；新的成功替换文本并去掉标记，即使与上次文本完全相同也恢复成功。
- 控制器显示本次状态，成功状态才亮ready灯；错误提示仍保持原来的缺密钥/通用错误边界，D04再分类。清除展示错误不等于操作成功。复制反馈附带当前操作文案与旧结果标记，不掩盖当前失败/处理中。
- FXML状态栏可换行并触发窗口高度重算，避免小窗口长提示省略掉末尾的“上次结果”；设置和单词本按钮仍保留。未改变窗口焦点/快捷键行为。
- 新增7项协调器JUnit方法和7项展示模型JUnit方法；扩展旧逆序用例的状态断言，新增26项独立JavaFX检查。同步[增量测试指南](../core-tests.md)与[执行记录](../14天更新执行记录.md)。

## 用户影响与边界

状态依次显示“正在读取选区”“正在翻译”“翻译成功”；无选区显示“未选中文字，请选中后再按 Tab”，Unknown显示“无法读取选区，请尝试其他应用”。读取或服务抛出异常属于失败，不伪装成成功。保留的内容仍可复制，但明确标为上次结果，不认为它对应本次触发。

读取状态从通知进入trigger、排队等待工作时开始，不证明已完成按键瞬间的文本捕获；翻译进度可能短暂而被同一帧内的终态替代，不人为延时。保留结果标记在状态栏，不新增历史列表。

**丢弃旧状态/回调不等于取消HTTP或停止计费。** 服务仍用公共后台线程池，已在途请求及守卫与调用之间的并发窗口仍在；本次没有限流、取消或费用保障，也未提前实现在线开关/上传知情确认。
