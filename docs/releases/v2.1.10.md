# v2.1.10 — D10：窗口找回与监听会话关闭

实际执行：2026-10-22，Europe/Copenhagen；补2026-10-20的D10，不伪记准点。版本由pom.xml的2.1.9递增为2.1.10，不升级依赖，不发布安装包。

## 实际改动

- WindowGeometry按整个窗口与屏幕可用区域的交集选择显示器，夹紧窗口坐标。副屏消失回到第一可用屏；支持负坐标、分数逻辑坐标、无效数值。超大窗口只保证左上入口可达，不承诺全部内容适配。
- WindowPositionStore不再仅检查左上1像素；主窗显示后、内容resize、屏幕列表/输出缩放变化进行找回，不show/toFront/requestFocus。屏幕全局监听在隐藏时移除，重显可重新注册。保存坐标flush；异常不阻止退出，不读写个人配置用于测试。
- HotkeySession每次激活创建新服务，重复start不重复安装，close可重复，旧会话尚未开始执行的通知失效。启动失败清理并可重新激活；主窗隐藏即关闭会话，Application.stop再次关闭无害。
- WindowsTabObserverService拒绝关闭后重启同一实例，补启动超时后晚安装的closed检查，避免迟到安装进入永久消息循环。应用启动失败显示本地安全建议，不把外部异常/密钥写到UI。运行期间原生错误仍保留原诊断机制，未增加自动重启。

## 已知限制 / 待验证

- 真正拔插副屏、混合DPI、远程桌面、任务栏位置变化、超小工作区均未实机验证。逻辑矩形/真实单桌面FX测试不是多屏验收；超大窗口完整按钮布局和辅助设置窗口恢复仍待后续。
- 假服务会话反复启停不等于真实原生hook压力测试。PostThreadMessage/Unhook失败、系统阻塞超过join超时和OS级资源释放没有完整故障注入证明；close不是停止已经执行的回调/HTTP或停止计费。
- 主窗startup失败提示已有生产接线；未人工强制Windows安装hook失败。动效服务既有关闭/开关由窗口FX检查回归，不宣称实际主进程退出重启/干净机通过。
- 位置读写故障仅安全降级，不展示持久化成功，可能无法跨重启恢复；不迁移旧位置键。
