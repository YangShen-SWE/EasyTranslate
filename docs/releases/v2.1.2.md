# v2.1.2 — D02 latest trigger consistency / 最新触发一致性

日期：2026-10-12（Europe/Copenhagen）。内部源码更新，不是安装包发布。

## 当天目标与实际改动

- 模块pom.xml的project.version由2.1.1递增到2.1.2；未升级依赖、扩大module-info或修改既有2.1.0安装包下载入口。
- 新增LatestTranslationCoordinator：在trigger进入时分配递增意图编号，早于异步选区读取。编号通过闭包贯穿选区/服务工作和UI回调；后续意图不论最终Found、None或Unknown都会使旧意图失效。
- TranslateSelectionUseCase增加意图有效性检查与可注入工作Executor；工作开始前/读取结束后过滤已知过时工作。保留原构造器、execute()及默认后台执行，未大规模重构服务。
- 实际应用入口由Tab通知进入协调器；在Platform.runLater任务真正执行时复查有效编号，再发布译文或错误。编号检查和发布、trigger/close共享同一锁，避免只在UI排队前检查留下空隙。
- 主窗口WINDOW_HIDING及Application.stop均关闭协调器；关闭后拒绝新触发，尚未执行的工作在守卫看到关闭时跳过。排队或晚到的成功/失败均不能再更新窗口；已通过守卫的旧工作不承诺被取消。
- 增加13项真实协调器+真实用例的离线JUnit方法，以及6项真实JavaFX队列/文本绑定检查。更新[核心增量测试指南](../core-tests.md)与[执行记录](../14天更新执行记录.md)，同步用户授权的每日普通推送规则。

## 用户影响与未改变的边界

快速触发多次时，只允许最新意图发布成功或失败。新触发没有选区或无法判断选区时，旧请求不能趁机重新覆盖窗口；已有展示暂时保留，并非清空或已添加“旧结果”标记。本次操作状态和旧译文说明留给D03。

意图编号从Tab通知调用trigger时起生效，不是原生按键瞬间文本快照。选区仍在后台读取，用户切焦点/改选区仍可能影响实际捕获；没有引入剪贴板模拟复制、OCR或输入法接管。

**丢弃旧回调不等于取消HTTP或停止计费。** 已在途请求仍可能完成；选区结束后检查和服务实际调用之间存在并发窗口，不能保证所有过时请求完全不发送。没有改变真实API分类错误、重试、费用规则、隐私确认或在线开关。

由于修改应用入口到UI的接线，也扩展并运行现有FloatingWindowSmokeTest（独立JavaFX main）。先尝试：


本机Windows执行策略返回PSSecurityException / UnauthorizedAccess，脚本未启动，退出码1。没有修改执行策略或使用Bypass。改为执行已审查脚本中的同一编译与Java入口：

```powershell

  '--module-path' $uiDependencies '--add-modules' 'javafx.controls,javafx.fxml,com.sun.jna,com.sun.jna.platform' `
  '-cp' 'target/classes;target/test-classes' 'com.easytranslate.view.FloatingWindowSmokeTest'
```

编译/依赖路径生成退出码0；直接Java启动退出码0，**UI_SMOKE_PASSED: 63 checks**。新增6项验证真实FX线程、最新源文/译文绑定、旧排队错误不覆盖状态，以及协调器关闭后排队结果不改文本/状态。保留现有窗口、设置、布局与动效监听回归；使用临时Preferences节点与假文本/假密钥，不读取个人凭据，不发翻译请求。不把63项UI检查与28项JUnit合并计数。
