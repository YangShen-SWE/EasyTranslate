# v2.1.1 — D01 core test baseline / 核心测试基线

日期：2026-10-11（Europe/Copenhagen）。内部开发更新，不是安装包发布。

## Change / 实际改动

- 项目版本由2.1.0递增到2.1.1；权威源为模块pom.xml的project.version。未修改任何既有依赖版本、生产业务代码或module-info。
- 显式配置Maven Surefire 3.5.4，发现并执行JUnit 5；测试运行使用classpath，failIfNoTests=true。新增测试构建插件不是升级应用依赖。
- 新增TranslateSelectionUseCaseTest（7项）：真实用例的Found传递和单次调用、None/Unknown不翻译、选区/翻译异常、非调用线程执行，以及读取未完成时返回未完成Future。使用现有接口注入内存假服务，不大规模重构。
- 新增SelectionResultTest（8项）：Found空白处理、内部文本保留、空/空白/非法状态数据拒绝，以及None/Unknown契约。
- 新增[核心增量测试指南](../core-tests.md)和[14天更新执行记录](../14天更新执行记录.md)，说明定向执行、证据边界及重放检查。
