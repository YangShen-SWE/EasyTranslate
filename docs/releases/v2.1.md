# EasyTranslate v2.1

This release makes it easier to use EasyTranslate after installation. You can now enter, save, or delete your own DeepSeek API Key in the settings window. A saved key is encrypted for the current Windows user, and the app reads it for each new translation request. Missing keys and other translation failures show a message in the floating window.

The Windows installer includes the Java runtime. After installation, open **设置**, save your DeepSeek API Key, then select English text in another app and press **Tab**.

The settings window also keeps the small, medium, and large window sizes from Version 2; large remains the default. The API Key controls have been added to the same window.

**Known limits:** The vocabulary book is still a placeholder. Tab is still the fixed translation key, and there is no light theme yet. Selection reading does not work in every app, and an older translation can still arrive after a newer one. This installer is unsigned; a clean-machine installation and a real DeepSeek request with a personal key have not been verified in this round. See the [issue list](https://github.com/YangShen-SWE/EasyTranslate/blob/main/docs/待解决问题清单.md) for the remaining work.

Verification: the standalone UI check passed 57 checks, the packaged app image started locally, and the `.exe` installer was generated.

# EasyTranslate v2.1 中文说明

这次主要是让下载安装后的使用顺一点。现在可以在设置窗口输入、保存或删除自己的 DeepSeek API Key。保存后的密钥会针对当前 Windows 用户加密，每次新翻译都会读取最新的密钥。缺少密钥或翻译失败时，悬浮窗也会给出提示。

Windows 安装包已经带上 Java 运行环境。安装后打开**设置**，保存自己的 DeepSeek API Key，再去其他软件里选中英文，按 **Tab** 就能发起翻译。

第二版已有的小、中、大三档窗口大小还在设置里，默认仍然是大；这次把 API Key 的输入和删除也放进了同一个窗口。

**目前的限制：**单词本还是占位窗口；翻译快捷键仍然固定为 Tab，也还没有白天模式。不是所有软件都能读到选区，连续翻译时旧请求仍可能晚到。安装包尚未签名，这一轮也还没在干净的 Windows 机器上完整安装，或用个人密钥验证真实 DeepSeek 请求。剩下的事记在[待解决问题清单](https://github.com/YangShen-SWE/EasyTranslate/blob/main/docs/待解决问题清单.md)。

验证情况：独立界面检查通过 57 项；打包后的应用镜像在本机启动过，`.exe` 安装包已生成。
